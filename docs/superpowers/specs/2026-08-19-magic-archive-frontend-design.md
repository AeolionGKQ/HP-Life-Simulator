# 魔法档案前端视觉重构设计规范

## 目标

在不改变游戏业务逻辑、后端接口、状态流、字段顺序和操作意图的前提下，将测试用前端重构为适合长时间游玩的沉浸式魔法叙事界面，并确保仍可正确连接本地 FastAPI 后端与 LLM 配置服务。

## 设计方向

采用已确认的“电影感魔法档案”方案。页面是一个夜间开放的魔法学院档案室，而不是营销落地页：界面应退居故事之后，以编辑式排版、暖黑色面、发丝边界和克制动效营造氛围。

设计刻度固定为：

- `DESIGN_VARIANCE=7`
- `MOTION_INTENSITY=4`
- `VISUAL_DENSITY=6`

## 视觉系统

### 色彩

- 固定夜间主题，不提供主题切换。
- 画布使用深森林墨色，主要表面使用稍亮的暖黑绿。
- 正文使用羊皮纸白，次要文字使用中性灰褐。
- 琥珀金是唯一品牌强调色，只用于主操作、选中态、焦点和关键数值。
- 成功、错误和危险可使用低饱和语义绿、锈红，但不得作为第二品牌色。
- 不使用通用 AI 紫色渐变，不使用大面积玻璃拟态。

### 字体

- 品牌标题、章节标题和剧情正文使用本机中文衬线字体栈，体现古老书卷与文学叙事。
- 表单、按钮、数据、状态和辅助说明使用系统无衬线字体栈，保证高密度信息可读性。
- 不依赖网络字体。

### 形状与层次

- 常规控件使用 4px 到 8px 小圆角，重要容器不超过 12px。
- 通过表面色差、1px 发丝边界和留白建立层次，常规卡片不使用阴影。
- 所有可交互元素必须有默认、悬停、焦点、禁用和选中状态。
- 移动端主要触控目标高度不低于 44px。

### 图标与动效

- 新增且仅新增一个生产依赖 `@phosphor-icons/react`，用统一线性图标替换装饰性 emoji 和字符图标。
- 不新增动效依赖。页面进入、菜单选择、加载和弹窗使用 CSS 动效。
- 所有非必要动效在 `prefers-reduced-motion: reduce` 下关闭。

## 信息架构与组件

### 顶部与欢迎区

- 保留应用名称、后端状态、LLM 状态和配置入口。
- 欢迎区采用不对称编辑式布局，左侧呈现时代和叙事引导，右侧呈现模型服务状态。
- 不制作占据整屏的营销 Hero；首屏必须同时看见主要游戏入口。

### 游戏工作区

- 桌面端保持“档案索引侧栏 + 主内容”两列结构，容器最大宽度约 1360px。
- 侧栏明确标记当前栏目，世界线偏移作为独立数据状态呈现。
- 主内容区优先保证剧情正文的舒适阅读宽度与 1.85 到 2.0 行高。
- 人物、纪事、关系、恋爱、声望、课程、信件和世界线沿用统一的信息行、状态格和档案卡片语法。

### 创建角色

- 保留现有 13 步顺序、选项内容、回答方式和确认逻辑。
- 强化当前步骤、总进度、已选选项、不可用选项和继续操作的视觉层级。
- 文本回答区在桌面端与主操作并排，在移动端垂直堆叠。

### 剧情与行动

- 剧情正文是主视觉焦点，选择项位于正文之后，不与标题竞争。
- 选项的收益、损失、风险和说明保持现有数据映射，只调整排版。
- 自由行动输入继续支持 Enter 提交，不改变交互逻辑。

### 存档与配置

- 存档卡片保留选择、重命名、删除和版本信息。
- LLM 配置弹窗保留 Base URL、API Key、模型名、保存和测试连接功能。
- 弹窗增加标准对话框语义、清晰关闭按钮和可见焦点，但不改变保存与测试请求。

## 响应式

- `> 900px`：两列工作区与完整顶部布局。
- `641px - 900px`：侧栏变为可横向滚动的档案标签栏，主内容全宽。
- `<= 640px`：顶部、欢迎区、表单操作和存档卡片垂直堆叠；文字大小和间距收紧但不隐藏功能。
- 页面不得出现非预期横向溢出。

## 技术边界

- 允许修改：`frontend/src/App.tsx`、`frontend/src/GameView.tsx`、`frontend/src/styles.css`、`frontend/package.json`、`frontend/package-lock.json`，以及新增的 Playwright 配置与测试文件。
- 禁止修改：`frontend/src/api.ts`、后端接口、数据库结构、LLM 配置格式、游戏状态转换、菜单名称、角色创建步骤和 API 请求负载。
- 不创建或删除用户真实存档来获取截图。代表性状态使用 Playwright 路由拦截构造。
- 不读取、输出或截图 API Key。

## 验收标准

- Windows 原生 Node 环境下 `npm run build` 成功。
- Windows 原生 Python 虚拟环境下后端测试全部通过。
- 真实 FastAPI 后端启动后，前端能读取 `/api/health`、`/api/config/llm`、`/api/sessions` 和 `/api/content/eras`。
- Playwright 自动化验证首页、配置弹窗、创建向导和剧情状态的主要语义与交互入口。
- 生成并人工审查 1440x1000 桌面截图和 390x844 移动截图，覆盖首页、创建向导、剧情和配置弹窗。
- 截图中无横向溢出、控件截断、文字重叠、低对比主按钮或未处理的加载状态。

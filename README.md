# 霍格沃兹人生模拟器 v2.3

你的名字还没有写进校史。

《霍格沃兹人生模拟器》是一款本地运行、单人游玩的纯文字连续叙事人生模拟游戏。你会从角色创建开始，经历入学、课程、友谊、秘密、选择和成长；模型负责主持故事与扮演 NPC，程序负责保存和裁决角色状态。

你不需要扮演救世主，也不必沿着原著路线前进。你可以在熟悉的历史旁边，建立一段真正属于自己的魔法人生。

> 本项目是免费、非商业的同人游戏，与 J.K. Rowling、Warner Bros. Entertainment 或 Wizarding World 官方无关。

## v2.3 更新内容

更新日期：2026-08-21

### 【v2.3 新增】完整羁绊系统

本版本将好感、信任、普通关系和恋爱统一为【羁绊】系统。

- 好感和信任分别记录，范围均为 `0—100`。
- 模型只能提交相对变化，程序负责最终裁决。
- 单个 NPC 单轮好感和信任最多变化 `±10`。
- 只有真实发生对话、帮助、冲突、共同经历或明确关系事件时，才会产生羁绊变化。
- 普通关系阶段包括：
  - 陌生；
  - 相识；
  - 朋友；
  - 挚友；
  - 疏远；
  - 敌对。
- 普通关系阶段需要满足互动证据、好感/信任阈值和逐级推进规则。
- 恋爱阶段独立于普通关系阶段，包括：
  - 尚未开放；
  - 暂无恋爱关系；
  - 恋爱中；
  - 稳定恋情；
  - 成年亲密关系；
  - 婚姻。
- 未满 12 岁只能发展普通羁绊。
- 12—17 岁最多进入普通恋爱阶段。
- 成年亲密关系和婚姻需要玩家与 NPC 双方都已成年。
- NPC 年龄未知或双方年龄不符合规则时，程序不会批准恋爱阶段。
- 跨生日时会立即使用本回合最终日期重新计算年龄。
- 年龄暂时不满足的阶段会进入待解锁列表，并由程序自动复核。

### 【v2.3 新增】模型创建原创 NPC 与新羁绊

玩家不再只能和预设 NPC 建立关系。

当玩家在剧情中真实遇见一个值得长期记录的新人物时，模型可以提出结构化的新羁绊对象：

- 新人物拥有姓名、身份、年龄或年龄段、地点、性格、目标和恐惧。
- 稳定 `npc_id` 由程序生成，模型不能直接决定数据库 ID。
- 程序会检查姓名、别名、身份和地点，避免重复创建同一个人。
- 每轮最多创建一个新的 NPC。
- 新人物默认从陌生或相识开始。
- 新人物不会因为被创建就自动喜欢玩家。
- 创建回合不能直接进入挚友、稳定恋情、成年亲密关系或婚姻。
- 新人物会写入本地存档，并在后续回合中持续发展。

这意味着你可以：

```text
在图书馆帮助一个陌生学生
→ 认识并记住这个人
→ 建立一段新的羁绊
→ 在后续人生中继续发展这段关系
```

### 【v2.3 新增】时代背景与主线动态提示词

模型不再每轮只收到一句压缩的世代主线，而是会收到分层的时代背景：

- `era_frame`：时代范围、历史情绪、社会状态和核心氛围。
- `mainline_phase`：当前世代正在发展的阶段主线。
- `timeline_phase`：根据日期、年级、学年和学籍计算的当前时间线位置。
- `worldline_pressure`：世界线偏移、已改变节点、正在靠近的历史压力和叙事指导。
- `relevant_nodes`：根据当前地点、行动和近期记忆筛选出的相关主线节点。

子世代已经拆分为六个阶段：

1. 来信与入学；
2. 城堡旧秘密；
3. 密室与恐惧；
4. 逃犯与时间；
5. 比赛与战争阴影；
6. 分裂、抵抗与霍格沃茨之战。

1998 年霍格沃茨之战结束后，剧情会进入“战后的余波”，不会继续把已经结束的战争写成正在发生。

主线始终是历史背景和因果压力，不是强制任务列表。玩家可以：

- 参与或旁观原著事件；
- 错过、误解、延后或改变历史节点；
- 与原著角色保持距离；
- 建立完全独立于原著的个人故事；
- 在改变世界线的同时承担人物、关系、声望和后续因果代价。

## 之前版本的功能

### v2.2

- 总体声望系统，范围 `-100—100`，分为九个声望等级。
- 声望会影响模型对 NPC 信任、猜疑、帮助和偏见的判断。
- 声望达到“黑巫师”或更低等级时，程序会自动开除仍在校的角色。
- 自动开除会清空当前课程、保留课程历史和技能，并弹出离校通知。
- 离校后不能以普通学生身份复学，但可以作为教授、工作人员、盟友或战斗人员合理返回学校。
- 角色创建剧情起点收束为四个预设节点：
  - 收到霍格沃茨来信之前；
  - 第一次踏入对角巷；
  - 九又四分之三站台；
  - 分院时。
- 人物称呼遵守西方姓名顺序、社交距离和中间名规则。
- 课程与技能字段在前端统一显示中文。

### v2.1

- 【干涉命运】功能。
- 玩家可以指定下一幕必须发生的核心事件。
- 模型会补足当前剧情和目标事件之间的自然过渡。
- 使用后当前节点立即结束，下一节点仍然返回正常选项。
- 干涉命运不能绕过年级、年龄、课程、技能、生命周期和程序状态规则。

### v2.0

- 完整年级和学籍系统：
  - 分院完成后进入一年级；
  - 一至七年级按学年推进；
  - 九月新学期开始时升年级；
  - 支持辍学、开除、毕业和 O.W.L. 后离校。
- 完整课程和选修系统：
  - 一年级核心课程；
  - 三年级选修课；
  - 六年级 N.E.W.T. 课程；
  - 课程状态由程序和课程 API 维护。
- 技能熟练度与经验成长：
  - 熟练度范围 `0—10`；
  - 经验范围 `0—100`；
  - 经验达到 100 后自动升级并清零。
- 六月课程技能年度结算。
- O.W.L. 与 N.E.W.T. 成绩记录。
- 角色确认后生成初始资源和长期维度。
- 历史剧情节点浏览，历史节点只读。
- 日期不能倒退，地点使用稳定 ID。
- 选项风险分为低、中、高、致命四级。
- 守护神潜在形态与【呼神护卫】技能规则。
- 长期记忆、故事摘要、关键秘密和未完成线索。

## 你可以怎么玩

- 创建一个属于自己的巫师角色。
- 选择世代、姓名、出身、性格、价值观、魔杖、魔法天赋、宠物、初始好友、剧情起点和学院。
- 在连续剧情中点击选项，或选择“其他”直接输入行动。
- 探索霍格沃兹、对角巷、车站、图书馆、禁林和其他故事地点。
- 学习课程、练习魔法、提升技能、收集物品、获得状态和词条。
- 和预设 NPC 或剧情中遇到的原创角色建立羁绊。
- 观察声望、世界线和人物关系如何随选择变化。
- 使用【干涉命运】指定一个希望发生的剧情节点。
- 随时查看角色、纪事、羁绊、恋爱、声望、课程、信件和世界线档案。
- 创建多个独立存档，分别体验不同的人生。

查看档案页面不会推进剧情，也不会消耗行动。

## 角色创建

第一次开始游戏时，你会完成一份 18 步角色档案：

1. 选择故事世代；
2. 填写姓名；
3. 选择性别；
4. 填写生日；
5. 描述外貌；
6. 选择家庭出身；
7. 选择童年经历；
8. 选择性格，可多选；
9. 填写价值观；
10. 设定魔杖；
11. 选择魔法天赋，可多选；
12. 选择宠物；
13. 选择初始好友；
14. 选择剧情开始的时刻；
15. 选择学院倾向；
16. 选择潜在的守护神形态；
17. 写下角色补充设定；
18. 确认角色档案。

角色补充设定会持续影响后续叙事，但不能绕过年龄、课程、技能、学籍、羁绊和其他程序规则。

当前开放的世代是：

- **子世代：1991—1998**，与哈利、罗恩、赫敏同窗七年，经历秘密、恐惧、战争和霍格沃茨之战。

其他世代内容已保留统一配置结构，当前版本暂未开放。

## 模型与状态规则

模型负责：

- 讲述原创剧情；
- 扮演 NPC；
- 提供行动选项；
- 判断叙事结果；
- 提出结构化状态变化；
- 提出长期记忆；
- 在真实互动后提出关系变化或新羁绊对象。

程序负责：

- 保存玩家、NPC、关系和世界线状态；
- 校验日期、地点、年级和课程；
- 校验资源、属性、技能和经验；
- 校验声望变化；
- 校验羁绊数值、阶段、年龄和新 NPC；
- 裁剪或拒绝非法模型提案；
- 记录回合审计。

模型不能直接：

- 覆盖玩家最终属性；
- 跳级或降级；
- 绕过年龄进入恋爱阶段；
- 凭空让 NPC 喜欢玩家；
- 直接创建数据库 ID；
- 修改玩家总体恋爱状态；
- 修改课程状态；
- 修改声望等级边界；
- 改变 JSON 输出协议。

```text

```

## 安装与启动

### 环境要求

- Windows 10 或 Windows 11；
- Python 3.12 或更高版本；
- Node.js LTS；
- 一个支持 OpenAI-compatible Chat Completions 格式的模型服务；
- 模型服务的 Base URL、API Key 和模型名称。

### 第一次启动

1. 克隆或下载本仓库。
2. 将 `config/settings.example.toml` 复制为 `config/settings.local.toml`。
3. 编辑 `config/settings.local.toml`：

```toml
[llm]
base_url = "你的模型服务地址"
api_key = "你的 API Key"
model = "你的模型名称"
timeout_seconds = 300
temperature = 0.8
```

4. 双击 `start_hp_simulator.bat`。
5. 等待浏览器打开 `http://127.0.0.1:5173`。

启动器会在第一次运行时检查并安装后端和前端依赖，然后分别启动 FastAPI 后端和 Vite 前端。

也可以手动启动：

```powershell
python -m pip install -e ".[dev]"
npm --prefix frontend install
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

另开一个终端启动前端：

```powershell
npm --prefix frontend run dev
```

### 模型配置说明

默认配置文件为：

```text
config/settings.local.toml
```

程序也提供页面内模型配置入口，可以填写和测试模型连接。

请不要提交或分享以下内容：

- `config/settings.local.toml`；
- API Key；
- `data/` 存档目录；
- 模型服务返回的私密剧情内容。

## 存档与隐私

- 游戏存档保存在本机 SQLite 数据库中。
- 每个存档彼此独立，可以重命名或删除。
- 存档不会自动上传到 GitHub。
- 删除存档无法撤销，升级前建议备份 `data/`。
- 剧情、行动和相关角色状态会发送给你配置的模型服务。
- 请阅读模型服务商的隐私政策和数据保留规则。
- 不要把 API Key、配置文件或本地存档提交到公共仓库。

## 常见问题

### 找不到 Python

安装 Python 3.12 或更高版本，并确认安装时勾选了加入 PATH。

### 找不到 npm

安装 Node.js LTS，然后重新打开终端或重新运行启动器。

### 模型连接失败

检查：

- Base URL 是否完整；
- API Key 是否有效；
- 模型名称是否正确；
- 账户是否有额度；
- 模型服务是否支持 OpenAI-compatible Chat Completions；
- 本地网络是否可以访问模型服务。

### 页面没有自动打开

手动访问：

```text
http://127.0.0.1:5173
```

### 剧情生成较慢

模型生成和修复请求可能需要较长时间。请等待当前回合完成，不要连续重复点击。

### 如何备份存档

关闭游戏后复制整个：

```text
data/
```

恢复时，将备份目录放回项目根目录即可。

# 霍格沃兹人生模拟器 V1.1

一封来自魔法世界的邀请已经送达。

在这款单人文字人生模拟游戏中，你将创建属于自己的年轻巫师，选择出身、性格、魔杖、天赋与人生起点，然后在不断展开的故事里学习课程、结识伙伴、面对危险，并亲手改变熟悉的世界线。

> 本项目为免费、非商业的同人游戏，与 J.K. Rowling、Warner Bros. Entertainment 或 Wizarding World 官方无关。

## V1.1 可以体验什么

- 全新的“魔法档案”界面，支持桌面与移动浏览器。
- 13 步角色创建：姓名、外貌、出身、童年、性格、价值观、魔杖、天赋、宠物、好友与剧情起点等。
- 由大语言模型主持的连续剧情，可选择预设行动，也可输入自己的自由行动。
- 角色状态、物品、技能、词条、关系、声望、课程、信件、纪事与世界线记录。
- 多个彼此独立的本地存档，可重命名或删除。
- 自动保存；关闭页面后，下次仍可继续原来的故事。

当前正式开放的是 **子世代（1991—1998）**。邓布利多时代、亲世代和现代会在后续版本逐步开放。

## 开始前需要准备

- Windows 10 或 Windows 11。
- [Python 3.12 或更高版本](https://www.python.org/downloads/)，安装时勾选 **Add Python to PATH**。
- [Node.js](https://nodejs.org/)（建议使用当前 LTS 版本）。
- 一个兼容 OpenAI Chat Completions 格式的模型服务，并准备好：
  - Base URL
  - API Key
  - 模型名称

模型服务可能产生费用。开始游玩前，请先了解服务商的计费、内容与隐私政策。

## 下载与部署

### 方法一：下载正式版（推荐）

1. 打开本仓库右侧的 **Releases**。
2. 选择 **霍格沃兹人生模拟器V1.1**。
3. 在 Assets 中下载 Source code（zip）。
4. 将压缩包完整解压到一个固定目录，例如：

   ```text
   D:\HP Simulator
   ```

5. 不要直接在压缩包预览窗口中运行游戏。

### 方法二：使用 Git 克隆

```powershell
git clone https://github.com/AeolionGKQ/HP-Life-Simulator.git "D:\HP Simulator"
cd "D:\HP Simulator"
```

## 配置模型服务

首次启动前，在项目根目录打开命令提示符或 PowerShell，创建一份只属于本机的配置：

```powershell
copy config\settings.example.toml config\settings.local.toml
```

然后选择下面任一种方式填写配置。

### 在游戏界面中配置（推荐）

1. 双击 `start_hp_simulator.bat` 启动游戏。
2. 浏览器打开后，点击页面右上角的模型配置按钮。
3. 依次填写 Base URL、API Key 和模型名称。
4. 点击“测试连接”。
5. 测试成功后保存。

### 直接编辑配置文件

用记事本打开 `config\settings.local.toml`，找到 `[llm]`，填写：

```toml
[llm]
base_url = "https://你的服务地址"
api_key = "你的 API Key"
model = "你的模型名称"
```

请保留英文引号，不要把配置文件发给他人，也不要将它上传到公开仓库。

## 启动游戏

双击项目根目录中的：

```text
start_hp_simulator.bat
```

首次运行会自动安装所需组件，可能需要几分钟，请保持网络连接并不要关闭弹出的窗口。准备完成后，浏览器会自动打开游戏。

以后启动仍然双击同一个文件即可。游玩期间请保留“Backend”和“Frontend”两个命令窗口；关闭它们会停止游戏。

## 第一次游玩

1. 在欢迎页选择“建立新档案”。
2. 为存档命名。
3. 完成 13 步角色创建。
4. 在最后的档案预览页确认设定。
5. 开始第一幕剧情。

角色创建中的大部分项目都可以使用预设，也可以填写自己的内容。性格与魔法天赋支持多选；魔杖由木材、杖芯和规格共同组成。

## 如何推进故事

每个回合会展示当前场景、故事正文和多个行动选项。

- 点击普通选项：按照该行动继续故事。
- 选择“其他”：输入任何合理的自由行动。
- 留意选项提示：部分行动可能获得或失去物品、状态、技能与词条。
- 等待魔法书写完成：模型生成剧情时不要重复点击。

你的关系、经历、能力和关键选择会影响后续故事。熟悉原著并不意味着故事一定沿着原来的轨迹发展。

## 档案菜单

- **角色**：查看身份、属性、物品、技能、状态与词条。
- **纪事**：回顾重要经历和剧情记录。
- **关系与好感**：查看认识的人以及当前关系变化。
- **恋爱**：查看已经进入恋爱阶段的关系。
- **声望**：了解不同群体对你的看法。
- **课程**：查看课程与学习情况。
- **信件**：查看收到的信件。
- **世界线**：观察你的行动对故事产生的偏移。

查询档案不会推进时间，也不会消耗一次剧情行动。

## 存档管理

- 游戏会自动保存，无需手动点击保存。
- 欢迎页可以选择已有档案继续游玩。
- 存档名称可以修改。
- 删除档案无法撤销，请确认后再操作。
- 存档只保存在本机；更换电脑或删除项目数据前，请自行备份 `data` 文件夹。

升级新版本时，建议先备份 `data` 文件夹和 `config\settings.local.toml`。

## 常见问题

### 双击后提示找不到 Python

重新安装 Python 3.12 或更高版本，并确认安装程序中的 **Add Python to PATH** 已勾选。安装后重新打开游戏目录再启动。

### 双击后提示找不到 npm

安装 Node.js LTS，完成后重新启动电脑或退出并重新登录 Windows。

### 首次安装依赖失败

确认网络可以访问 Python 和 Node.js 的软件源，然后重新双击启动文件。若使用代理，请确保命令行也能使用该代理。

### 页面没有自动打开

确认两个游戏窗口仍在运行，然后在浏览器访问：

```text
http://127.0.0.1:5173
```

### 模型连接测试失败

依次检查：

1. Base URL 是否正确，末尾不需要手动添加聊天接口路径。
2. API Key 是否完整且仍然有效。
3. 模型名称是否与服务商提供的名称完全一致。
4. 账户是否有余额或调用额度。
5. 网络、代理或防火墙是否阻止了模型服务。

### 剧情生成很慢

生成速度取决于所选模型、服务商负载和网络状况。等待生成完成后再继续操作；重复点击不会让生成更快。

### 如何完全退出

关闭浏览器页面后，再关闭标题中带有 “HP Simulator” 的两个命令窗口。

## 隐私与 API Key 安全

- API Key 和模型配置保存在本机的 `config\settings.local.toml`。
- 游戏存档保存在本机的 `data` 文件夹。
- 这些本地文件不会包含在 GitHub Release 中。
- 剧情文本会发送给你配置的模型服务，请以该服务商的隐私政策为准。
- 不要把 `LLM API KEY.txt`、`settings.local.toml` 或存档文件上传、截图或分享给他人。

## 游玩建议

- 先用预设完成一个角色，熟悉流程后再创建高度自定义的档案。
- 自由行动尽量写清楚“想做什么、对谁做、希望达到什么目的”。
- 把重要承诺、秘密和人物关系当成真正的长期选择。
- 在重大版本升级前备份自己的档案。

# 霍格沃兹人生模拟器 v2.0

你的名字还没有写进校史。

在《霍格沃兹人生模拟器》中，你会从一封猫头鹰来信开始，创建一个真正属于自己的巫师角色：决定出身、性格、魔杖、天赋、朋友、学院与潜在的守护神。之后的每一步都由你选择——去上课、结交朋友、追查秘密、练习魔法，或者做出一个可能改变整条世界线的决定。

这是一款单人、纯文字、连续叙事的人生模拟游戏。故事会记住你的经历，人物会记住你的选择，能力会随着学习和行动成长。你不需要扮演“救世主”，也不必沿着原著路线前进；你只需要成为这个世界里的自己。

> 本项目是免费、非商业的同人游戏，与 J.K. Rowling、Warner Bros. Entertainment 或 Wizarding World 官方无关。

## 你可以怎么玩

- 创建一个属于自己的巫师角色。
- 在连续剧情中做出选择，或直接写下你想采取的行动。
- 探索霍格沃兹、对角巷、车站、图书馆和其他故事地点。
- 与熟悉的人物和原创角色相遇，逐渐建立友谊、信任与更深的关系。
- 学习课程、提升技能、收集物品、获得状态与特殊词条。
- 观察自己的声望如何在不同群体中变化。
- 记录重要经历、长期记忆、关键秘密和未完成的故事线索。
- 查看世界线偏移，感受你的选择如何改变熟悉的历史。
- 随时打开角色、纪事、关系、课程、信件和世界线档案，不会因此消耗剧情行动。
- 创建多个独立存档，分别体验不同的人生。

## v2.0 带来的新内容

以下内容是 v2.0 的主要更新：

- **【v2.0 新增】完整年级与学籍系统**
  - 分院完成后进入一年级。
  - 一至七年级按学年推进。
  - 九月新学期开始时升年级。
  - 离校、辍学、开除、毕业等状态会被记录。

- **【v2.0 新增】完整课程与选修系统**
  - 一年级自动开始七门核心课程和飞行课。
  - 三年级选择两至三门选修课。
  - 六年级根据 O.W.L. 成绩选择 N.E.W.T. 课程。
  - 课程列表、选课资格和课程状态由游戏规则维护。
  - 可以直接从课程面板查看和调整高年级课表。

- **【v2.0 新增】技能熟练度与经验成长**
  - 技能熟练度范围为 `0—10`。
  - 技能经验范围为 `0—100`。
  - 经验达到 100 后，技能自动提升一级并清零经验。
  - 课程学习、剧情行动和直接技能提升可以共同影响角色成长。
  - 角色面板会显示熟练度 `x/10` 和经验 `x/100`。

- **【v2.0 新增】六月课程结算**
  - 每年六月，仍在修读的课程技能自然提升一级。
  - 同一年不会重复结算。
  - 退掉的课程会保留已有技能，但不再获得自动的年度成长。

- **【v2.0 新增】O.W.L. 与 N.E.W.T. 成绩**
  - 五年级进行 O.W.L.。
  - 七年级进行 N.E.W.T.。
  - 成绩会影响后续课程选择、毕业和未来道路。

- **【v2.0 新增】更完整的初始属性**
  - 角色确认后，游戏会根据角色设定生成初始资源和长期维度。
  - 生命、魔力、精神、精力、饱食度会在故事中持续变化。
  - 体质、智力、意志、魅力和魔力强度会影响行动表现。

- **【v2.0 新增】历史剧情浏览**
  - 可以查看上一节点和下一节点。
  - 历史节点只读，不会因为回看旧剧情而重复触发行动。

- **【v2.0 新增】更可靠的魔法档案**
  - 日期不能倒退。
  - 地点使用稳定的故事地点记录。
  - 选项会显示低、中、高、致命四级风险。
  - 角色创建时选择的守护神只是潜在形态，学会【呼神护卫】后才能真正召唤。

## 角色创建

第一次开始游戏时，你会完成一份 18 步角色档案：

1. 选择故事世代。
2. 填写姓名。
3. 选择性别。
4. 填写生日。
5. 描述外貌。
6. 选择家庭出身。
7. 选择童年经历。
8. 选择性格，可多选。
9. 填写价值观。
10. 设定魔杖。
11. 选择魔法天赋，可多选。
12. 选择宠物。
13. 选择初始好友。
14. 选择剧情开始的时刻。
15. 选择学院倾向。
16. 选择潜在的守护神形态。
17. 写下角色补充设定。
18. 确认角色档案。

角色补充设定会持续影响后续叙事，但不会绕过年龄、课程、技能和其他游戏规则。

## 故事与行动

每个剧情回合都会展示当前场景、正文和行动选项。

- 点击一个选项，让角色采取对应行动。
- 选择“其他”，直接写下自己的行动。
- 留意选项旁的风险提示。
- 选项可能带来物品、状态、技能、词条或关系变化。
- 失败也是故事的一部分，危险的选择不会被强行改写成成功。
- 生成剧情时可以查看其他档案页面，写作完成后再回到剧情继续。

模型负责讲述故事、扮演人物和提出可能的变化；游戏会负责保存和检查角色状态。你的每一次选择都会成为这条世界线的一部分。

## 课程与成长

课程页面会显示当前年级、学年、学期、正在修读的课程、课程技能、考试成绩和年度记录。

课程技能的成长有两条路：

- 在六月完成当前课程的年度学习，技能自然提升一级。
- 在剧情中通过练习、课程表现或关键事件获得经验。经验达到 100 后自动升级。

课程技能不会因为退课而消失，但退课后不会继续获得该课程的六月自然成长。重新选回课程时，会沿用原来的技能等级。

## 档案页面

- **角色**：身份、属性、技能、经验、状态、词条、物品与宠物。
- **纪事**：已经发生的重要故事。
- **关系与好感**：你认识的人、好感、信任与关系阶段。
- **恋爱**：已经进入恋爱阶段的关系。
- **声望**：不同群体对你的看法。
- **课程**：年级、学年、课表、技能和考试成绩。
- **信件**：收到的猫头鹰信件。
- **世界线**：你的选择对原本历史轨迹造成的偏移。

查看这些页面不会推进剧情。

## 如何开始

### 第一次安装

请准备一台 Windows 10 或 Windows 11 电脑，并安装：

- Python 3.12 或更高版本；
- Node.js，建议使用 LTS 版本；
- 一个支持 OpenAI Chat Completions 格式的模型服务，以及对应的 Base URL、API Key 和模型名称。

模型服务可能产生费用，请提前确认服务商的收费和隐私政策。

### 启动游戏

1. 从 GitHub Releases 下载 **霍格沃兹人生模拟器v2.0**。
2. 将压缩包完整解压到一个固定文件夹。
3. 将 `config/settings.example.toml` 复制为 `config/settings.local.toml`。
4. 打开游戏目录中的 `config/settings.local.toml`，填写模型服务信息。
5. 双击 `start_hp_simulator.bat`。
6. 等待浏览器自动打开游戏页面。

第一次启动会自动准备游戏需要的组件，可能需要几分钟。以后再次游玩时，直接双击同一个启动文件即可。

### 填写模型配置

在 `config/settings.local.toml` 中找到模型设置，填写：

```toml
[llm]
base_url = "你的模型服务地址"
api_key = "你的 API Key"
model = "你的模型名称"
```

也可以启动游戏后，在页面中的模型配置入口填写并测试连接。

请不要把 `settings.local.toml`、API Key 或 `data` 文件夹分享给其他人。

## 存档与安全

- 游戏会自动保存。
- 每个存档彼此独立，可以重命名或删除。
- 存档保存在本机，不会自动上传到 GitHub。
- 删除存档无法撤销。
- 升级版本前，建议备份 `data` 文件夹。
- 剧情内容会发送给你配置的模型服务，请以该服务商的隐私政策为准。

## 遇到问题时

- 如果提示找不到 Python：重新安装 Python，并确认安装时勾选了加入 PATH。
- 如果提示找不到 npm：安装 Node.js LTS 后重新启动游戏。
- 如果模型连接失败：检查地址、Key、模型名称、账户额度和网络。
- 如果页面没有自动打开：在浏览器访问 `http://127.0.0.1:5173`。
- 如果剧情生成较慢：请等待当前回合完成，不要连续重复点击。
- 退出游戏时，先关闭浏览器，再关闭游戏启动的两个命令窗口。

# 霍格沃兹人生模拟器 v3.6.3

> **致尚未入学，或正准备再次踏上站台的年轻巫师：** 你的名字，将由你亲手写进魔法世界。

猫头鹰送来的不只是一封入学通知，还有一段尚未落笔的人生。

《霍格沃兹人生模拟器》是一款单人连续文字叙事游戏。你将创造自己的巫师，在课程、友谊、秘密、声望与时代风暴中作出选择。故事会记得你结识的人、许下的承诺、学会的魔法，以及那些被你悄然改变的历史。

你不必成为救世主，也不必沿着原著走完一条早已写好的路。城堡里的每一道门、每一次迟疑和每一句没有说出口的话，都可能把人生带向另一条世界线。

> 本项目是免费、非商业的同人游戏，与 J.K. Rowling、Warner Bros. Entertainment 或 Wizarding World 官方无关。

## 四封来自不同时代的入学通知

v3.6.2 现已开放四条世代线，每一条都可以拥有独立存档：

- **邓布利多时代（1892—1899）：** 从戈德里克山谷的夏天走进霍格沃茨，结识尚未成为传奇的阿不思，并亲手迎接那个改变一切的 1899 年。
- **亲世代（1971—1981+）：** 与掠夺者、莉莉和斯内普同期入学，让七年青春一直延伸到第一次巫师战争及其漫长余波。
- **子世代（1991—1998）：** 从第一封入学通知启程，完整经历课程、考试、选修、N.E.W.T. 方向，以及原著年代接踵而至的风暴。
- **现代世代（2020+）：** 返回战后二十余年的霍格沃茨，在家族旧名、未愈伤痕与逐渐失控的时间因果中书写下一代的故事。

四段人生可以同时收藏、随时切换，也都能导出带走或导入另一台设备。你不必告别一条世界线，才能推开另一扇时代之门。

## v3.6.3：三处问题修复

- 修复剧情旁白使用“你”称呼玩家角色的问题，现在旁白会使用角色姓名。
- 修复玩家明确想与人物建立羁绊时未被优先记录的问题。
- 修复课程页面年度记录显示英文原始字段的问题，年级、课程与技能成长现已中文显示。

## v3.6.2：让未完成的记忆重新落笔

当一段人生走得足够长，命运卷宗会把每 25 个较早的剧情节点整理成一则阶段性故事弧，让多年以前的承诺、秘密与人物关系仍能在后来得到回应。v3.6.2 让这支负责整理记忆的羽毛笔变得更加可靠。

若模型服务暂时异常、等待超时，或返回的内容无法写入卷宗，尚未整理完的节点不会被遗忘，也不会从原始纪事中消失。它们会继续以摘要陪伴后续剧情，并在你写下下一幕之后自动再次尝试；不必手动追回失败的任务，更不必担心一段人生因此出现空白。

为了不让后台整理挤占整座猫头鹰棚，每次只会处理最早的一批记忆，即使已经积累了许多往事，也不会连续占满模型服务。界面会告诉你正在整理哪一段旅程：支持同时请求的服务允许你继续推进剧情，不支持的服务则会让下一幕暂时排队。看见提示时请不要退出或关闭游戏，整理完成后它会自行消失。

## v3.6.1：让羽毛笔按你的节奏思考

有些巫师愿意在每次选择前久久推演，有些巫师只想让下一页来得更快。v3.6.1 在顶部模型服务栏加入 **【模型思考】** 开关，让你在更细腻的因果判断与更轻快的叙事节奏之间自由取舍。

开关默认开启，适合人物关系复杂、历史分支交错或需要谨慎裁决的剧情；关闭后，剧情与初始属性等生成任务会尝试省去额外推理，通常能缩短等待，也可能减少模型消耗。不同模型服务采用的规则并不相同，但你不必研究那些晦涩参数——游戏会先替你试探、记住可用方式，并在服务拒绝时退回安全设置，避免之后每个回合都重复失败。

长期记忆不会为了速度牺牲完整性。故事弧的自动总结与【压缩全部故事弧】始终保留思考；压缩超时或失败时也会给出更明确的提示，不会删除原始剧情或损坏存档。

## v3.6：两段历史，等待你的名字

这一次，命运卷宗翻开了魔法史上最早、也最疼痛的两个年代。它们并非把熟悉的故事换一套名字重演：一个始于传奇尚未成名的少年时代，一个始于笑声仍能盖过远方战火的青春。

### 邓布利多时代：在传奇成为传说之前

时间回到 **1892 年的戈德里克山谷**。煤油灯、旧羊皮纸、雨后的湿土，还有一户不愿被打扰的邻居。

你带着录取通知书、魔杖与宠物回到村庄，先认识这座山谷，再走近邓布利多一家。阿不思聪明得过分，把求知欲与野心藏在礼貌之后；阿不福思更愿意守住眼前的家人；阿利安娜则被留在紧闭的门窗后，不会与你一同入学。九月以后，你将与他们度过完整七年——上课、冒险、建立信任，也替一个摇摇欲坠的家庭守住秘密。

到了 1899 年，死亡、责任与一个来自德姆斯特朗的耀眼青年会同时闯进阿不思的人生。“更伟大的利益”尚且只是一句写在羊皮纸上的理想，而你可以尝试守住这个家、质问这份理想，或成为它的第三位同行者。

如果想从十一岁开始见证传奇如何长成，就选择 1892 年的常规开局；如果更想立即走到命运裂开的地方，可以选择 **【直入终局】**，以刚刚毕业的成年巫师身份进入 1899 年。你与阿不思已经同窗七年、彼此信任，无须再从陌生人开始。两个终局起点一个留在风暴降临之前，另一个从悲剧发生的那一刻续写：追查真相、陪伴留下的人，或追随格林德沃驶向欧洲，选择权都在你手中。

### 亲世代：在笑声被战争碾碎之前

**1971 年 9 月 1 日**，蒸汽从车头升起，行李轮声混着唱片声。你会与詹姆·波特、小天狼星·布莱克、莱姆斯·卢平、彼得·佩迪鲁、莉莉·伊万斯和西弗勒斯·斯内普同期入学。

掠夺者不是四个已经成型的传奇，而是四个正在互相塑造的少年：詹姆爱出风头，小天狼星刚从古老家族的阴影里挣脱出来，莱姆斯温和克制并守着满月的秘密，彼得总在更耀眼的人身边寻找位置。莉莉聪明、敏锐又有原则；斯内普沉默敏感，把魔药与黑魔法当作力量。你可以成为他们中的一员、站到对面、在两边之间摇摆，也可以与这些名字保持距离，过完全属于自己的七年。

故事不会在毕业时结束。1978 年通过 N.E.W.T. 之后，你会脱下校袍，以成年巫师的身份继续生活；昔日同窗也将走向各自的职业、家庭与立场，而第一次巫师战争正在逼近。1981 年万圣夜同样不是句点——你可以参战、调查、发出警告、选择远离，甚至彻底错过那场改变时代的事件。之后的岁月会承接你建立的关系、留下的伤与握在手中的证据，而不是把所有人推回已经写好的结局。

### 你知道的历史，角色未必知道

凤凰社与食死徒都是秘密组织，不会因为你是学生就主动交出名单、据点或预言全文；斯莱特林也从来不等于食死徒。后来被写进史书的背叛、死亡与身份，在当时都只是尚未揭开的秘密。只有随着日期推进、亲身调查并取得证据，你的角色才有理由看见真相。

### 让漫长人生记住真正重要的事

旅程越长，命运卷宗里积累的故事弧就越多。现在可以前往侧边栏【记忆管理】，点击 **【压缩全部故事弧】**，将重复叙述与已经落幕的旧线索整理成一段更精炼的长期记忆。它会保留一路走来的范围，也不会删除任何原始剧情；那些曾经发生过的场景，仍然可以随时翻阅。

## 现代世代：时间会记得你的选择

现代世代的时代背景与核心冲突取材于[舞台剧《哈利·波特与被诅咒的孩子》](https://uk.harrypottertheplay.com/about-the-show/)。这部舞台剧建立在 J.K. Rowling、Jack Thorne 与 John Tiffany 共同创作的原始故事之上，并由 Jack Thorne 编剧。

原作发生在《死亡圣器》结局多年以后：哈利之子阿不思与德拉科之子斯科皮成为挚友，并试图借助时间转换器挽救塞德里克·迪戈里。一次次改写过去却让现实走向危险的分岔，德尔菲的真实身份与目的也逐渐浮出水面，使过去、现在与未来同时陷入危机。

游戏以这群人物和时间危机为现代线的故事土壤，但不会要求玩家重演舞台剧。你的原创巫师可以介入、阻止、误导或远离这条因果链，让熟悉的故事通向只属于这份命运卷宗的结局。

霍格沃茨大战已经过去二十多年。城堡表面恢复了日常，走廊里却仍藏着封存的房间、战后遗物、被改写的纪念碑，以及成年人不愿再提起的旧伤。

现代世代固定从 **2020 年 9 月 1 日、四年级、九又四分之三站台与霍格沃茨特快列车** 开始。阿不思·西弗勒斯·波特承受着英雄之子的期待，斯科皮·马尔福背负着家族旧名，而罗丝·格兰杰-韦斯莱也有自己的骄傲与选择。你的家庭、学院、出身和过往，同样会决定别人第一次看见你时想到什么。

### 一场尚未发生，却已经留下回声的危机

一架与旧历史有关的时间转换器重新成为传闻。阿莫斯·迪戈里的遗憾、塞德里克·迪戈里的命运，以及德尔菲隐藏的目的，可能把校园里的偶遇连成危险的因果链。

这不是一条要求你照本宣科的固定剧本。你可以：

- 帮助阿不思和斯科皮调查异常，也可以旁观、误导或阻止他们；
- 尝试保护塞德里克，拒绝介入，或把所谓“拯救历史”变成自己的筹码；
- 相信德尔菲、协助她寻找资源，或在证据足够后揭穿她；
- 追查时间转换器与战后遗物，也可以远离危机，专注校园、家庭、关系与未来；
- 在现实已经改变之后，承担人物记忆冲突、地点回声与替代历史留下的后果。

### 【时间扰动】不是一条善恶刻度

现代世代用【时间扰动】取代子世代的【世界线】。普通的上课、交友和探索不会让时间自动失控；只有真正触及历史因果的行动，才可能惊动这条沉睡的河流。

随着扰动加深，人物对过去的记忆可能变得模糊、冲突甚至碎裂，熟悉的地点也可能出现不属于当前现实的回声。修复时间线并不意味着一切从未发生：受过的伤、失去的信任、得到的物品和记住的秘密，仍会留在你的人生里。

现代线保留四年级与在校身份，但把重心放在探索、选择和人物关系上，因此**不启用课程、选课、考试、年度结算及课程技能成长**。子世代的完整校园成长玩法不受影响。

## 写下你的巫师档案

新人生会从一份角色档案开始。你可以决定姓名、性别、生日、外貌、家庭出身、童年经历、性格、价值观、魔杖、魔法天赋、宠物，以及那些只属于你的补充设定。

### 来路塑造目光，但不会锁死命运

纯血、混血、麻瓜出身与自定义家庭拥有不同的童年常识和入学背景。来路会影响角色如何理解眼前的人与事，却不会替你决定学院与未来立场。

古老家族的孩子可以反对纯血至上，麻瓜出身的学生也可能主动追逐危险知识。一个害怕失败、渴望证明自己、对某类魔法抱有偏见，或只想平安毕业的角色，往往比全知全能的天才更值得记住。

补充设定会持续影响叙事，但不会让角色无视年龄、学籍与尚未掌握的能力。潜在守护神也不会立刻回应召唤——你仍要在故事中真正学会【呼神护卫】。

### 从最适合这段人生的一页开始

不同世代会从各自最适合的那一页启程：

- **邓布利多时代：** 从 1892 年戈德里克山谷的夏天开始，或选择【直入终局】，直接以成年巫师身份进入 1899 年；
- **亲世代：** 从 1971 年 9 月 1 日的九又四分之三站台登车，与未来的朋友和对手一同入学；
- **子世代：** 可以从收到霍格沃茨来信之前、第一次踏入对角巷、九又四分之三站台或分院时开始，较晚的起点不会抹去童年与家庭背景；
- **现代世代：** 从 2020 年返校日开始。你已经是四年级学生，过往会写入档案，真正的故事则从列车鸣笛时重新落笔。

初始属性生成后，如果结果与设想不符，可以在踏入第一幕前展开【重新生成属性】，写下希望调整的方向。校准只属于尚未开始的人生，不会改动已经启程的存档。

## 在魔法世界里生活

### 每个回合都由你决定下一笔

你可以从故事给出的行动中选择，也可以点击“其他”，直接写下任何合理行动。与其只写“继续”，不如告诉故事你在观察谁、隐瞒什么、准备怎样的魔法，以及真正想冒险的方向。

翻阅角色、纪事、羁绊、声望、课程、世界线或时间扰动不会推进时间，也不会消耗行动。停下来整理线索，往往比匆忙走进下一扇门更重要。

### 羁绊来自共同经历

好感与信任会分别成长。一次友善招呼不会立刻换来生死之交，一场争执也未必足以摧毁多年友谊。对话、帮助、冲突、陪伴和共同冒险，才会让关系真正前进或后退。

你不只能和预设人物建立羁绊。图书馆里的陌生学生、禁林边缘的古怪巫师，或对角巷里怀揣秘密的学徒，都可能被故事记住，并在未来再次出现。

### 声望会先于你抵达房间

帮助他人、违反规则、公开使用某些魔法，都会慢慢塑造别人眼中的你。声望可能换来信任，恶名也可能带来畏惧、猜疑和敌意。

若在校期间彻底滑向黑巫师之名，霍格沃茨甚至可能将你开除。课程会结束，但人生不会；你仍要带着已经留下的名声走进下一段故事。

### 从一年级启程，就会完整经历学年成长

邓布利多时代、亲世代与子世代的常规开局都会陪你走过校园岁月。课程随年级变化，学习、练习和真正使用魔法会积累经验；三年级要面对选修，六年级将决定 N.E.W.T. 方向，六月则会留下成绩与成长。

退掉一门课不会抹去已经掌握的本领，但它也不会继续自然成长。考试失利、选错方向或错过机会并不等于这段人生失败，它们往往会打开更独特的道路。

### 历史是风暴，不是任务清单

无论是 1899 年的戈德里克山谷、第一次巫师战争、魔法石与密室，还是现代线的时间危机，时代事件都会在正确的日期逼近，却不会要求你逐项完成。你可以参与、旁观、错过、误解，甚至改变某个历史节点。

世界会根据日期、地点、近期行动与已经改变的往事，判断哪些风声此刻应该传到你耳边。你推开的不只是一扇门，还包括门后所有尚未写下的日子。

## 握住命运的羽毛笔

游戏提供两种不同的叙事工具。

### 【干涉命运】：告诉下一幕往哪里走

当你希望某件事在接下来的剧情中发生，可以写下目标。故事会尝试补足通往它的合理过程，而不是毫无铺垫地把结果放到面前。

干涉命运改变的是故事方向，不是一张无条件成功的许可证。年龄、能力、关系与已经发生的历史仍然有效。

### 【重塑命运】：让这一幕重新落笔

如果最新剧情节奏太快、人物行为失真，或故事误解了你的意图，可以在自由行动下方打开【重塑命运】，说明哪些内容应当保留、哪些地方需要改变。

```text
这一幕揭露秘密太快了。
保留“我已经察觉异常”，但让真相继续隐藏，
先通过脚步声、熄灭的烛火和人物反应制造悬念。
```

原版本带来的物品、技能、声望与羁绊变化会先被撤回，新版本只结算一次。简单来说：【干涉命运】推动下一幕，【重塑命运】改写这一幕。

## 记忆与命运卷宗

重要承诺、秘密、未完成线索和人物关系会进入长期记忆。最近发生的细节会被保留，更久远的旅程则会整理成阶段性的故事弧，让多年以后的一次重逢仍带着旧日余温。

这些整理不会擦去原始纪事。若一次整理未能成功，存档也不会受损；对应节点会继续作为摘要参与剧情，并在下一个新剧情节点写入后自动重试。当故事弧越来越多时，还可以使用【压缩全部故事弧】，把它们收束成一段更精炼的长期记忆，让往后的故事轻装前行，却不遗忘曾经走过的路。

### 一只档案柜可以收藏许多人生

在命运卷宗中点击【创建新存档】，便能保留现有人生并重新填写角色档案。你可以同时拥有谨慎的拉文克劳、野心勃勃的斯莱特林，或两个来路相同却走向完全不同时间线的人。

点击【导出】可以把一段人生保存为 `.hp-save.json` 文件；【读取存档】会创建带有“（导入）”标记的新副本，不会覆盖原卷宗。角色状态、剧情、纪事、人物关系、长期记忆、世界变化与故事弧都会随存档同行。

## 第一次游玩前的几条建议

- **给行动写出意图。** 说明你想观察、隐瞒、试探或保护什么，故事会更容易理解真正的选择。
- **给关系留下时间。** 多次共同经历，比一次夸张表白更能建立可靠羁绊。
- **经常翻阅纪事和线索。** 很多故事入口藏在已经见过的细节里。
- **允许失败成为人生的一部分。** 受伤、误会、失去信任和考试失利，常常会打开新的道路。
- **为不同念头建立不同存档。** 不必让一份卷宗承担所有可能的人生。
- **重要转折前先导出存档。** 命运可以冒险，珍贵记录最好另留一份。

## 从源码开启游戏

请克隆仓库，或从 Release 页面下载 Source code 并完整解压：

```bash
git clone https://github.com/AeolionGKQ/HP-Life-Simulator.git
cd HP-Life-Simulator
```

### 需要准备

- Windows 10/11、macOS 或 Linux；
- Python 3.12 或更高版本；
- Node.js LTS；
- 一个支持 OpenAI-compatible Chat Completions 的模型服务；
- 对应的 Base URL、API Key 与模型名称。

剧情生成需要联网访问你选择的模型服务。项目不会附带公共 API Key。

### Windows：双击启动

1. 确认 Python 与 Node.js 已安装，并且能够在命令行中使用。
2. 完整保留仓库目录结构，不要只单独复制启动脚本。
3. 双击项目根目录中的 **`start_hp_simulator.bat`**。
4. 首次启动会创建独立环境并准备所需内容，请保持网络畅通。
5. 浏览器打开后，在页面右上角填写模型配置并进行连接测试。

之后通常只需再次双击启动器。启动期间请保留弹出的窗口；关闭它会同时结束游戏服务。

若浏览器没有自动打开，可手动访问：

```text
http://127.0.0.1:5173
```

### macOS、Linux 或需要手动启动时

先在项目根目录创建本地配置。已有配置时不要覆盖：

```bash
cp config/settings.example.toml config/settings.local.toml
```

在第一个终端启动游戏服务：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

再打开第二个终端启动游戏页面：

```bash
cd frontend
npm ci
npm run dev -- --strictPort
```

保持两个终端运行，并访问 `http://127.0.0.1:5173`。

## 配置你的模型服务

进入游戏后，打开页面右上角的模型配置，填写 Base URL、API Key 和模型名称，再点击连接测试。

### Base URL 应该怎么填

这里只填写模型服务的**根地址**，不要附加具体接口路径。

以 OpenAI 官方服务为例，应填写：

```text
https://api.openai.com
```

不要填写：

```text
https://api.openai.com/v1
https://api.openai.com/v1/chat/completions
```

其他服务商的地址可能不同，请以对方提供的 OpenAI-compatible 接入说明为准。

连接测试失败时，请依次确认：

- Base URL 是否只填写了服务根地址；
- API Key 是否有效；
- 模型名称是否与服务商提供的名称完全一致；
- 账户是否有可用额度和对应模型的访问权限；
- 服务是否兼容 Chat Completions；
- 当前网络是否能够访问该服务。

### 【模型思考】：让故事更深，或让旅程更快

模型服务栏中的 **【模型思考】** 默认保持开启。支持推理的模型会在落笔前多做一轮判断，人物动机、复杂关系与长程因果通常会更稳妥；代价是等待可能更久，也可能消耗更多额度。

如果你更在意推进速度，可以关闭它；想让关键抉择得到更谨慎的处理时，再重新开启。这个选择会影响剧情、初始属性等需要你等待的生成任务，但**故事弧的自动总结与【压缩全部故事弧】始终保留思考**，让多年人生仍能维持连贯记忆。

第一次关闭时，游戏会发送一次很小的试探请求，寻找当前服务能够理解的方式。开关会短暂锁住并显示加载状态，请等它完成。如果服务只接受部分设置，游戏会记住可用组合；如果完全不允许关闭思考，开关会恢复开启并说明原因。即使正式生成时遇到严格的参数检查，游戏也会尝试撤去相关设置后安全重试一次，尽量不让一次兼容问题打断整段人生。

## 存档、更新与隐私

源码版的人生记录保存在项目目录下的 `data/` 中，本地模型配置保存在 `config/settings.local.toml`。

更新源码前，请先关闭游戏并备份：

- `data/`：所有本地存档；
- `config/settings.local.toml`：模型配置；
- 需要长期保存的 `.hp-save.json` 导出文件。

使用 Git 克隆的玩家可以在项目根目录执行：

```bash

```

更新后重新启动游戏。启动器会在需要时重新准备环境。若版本跨度较大，仍建议先导出重要存档。

请永远不要公开或提交：

- `config/settings.local.toml`；
- `LLM API KEY.txt` 或任何 API Key；
- `data/` 存档目录；
- `.hp-save.json` 导出文件；
- 你不希望交给他人的私密剧情内容。

游戏和存档保存在本机，但剧情生成会把相关故事内容发送给你配置的模型服务。不同服务商的数据保留规则不同，请在开始长期存档前阅读对应的隐私政策。

## 常见问题

### 双击启动器后提示找不到 Python

安装 Python 3.12 或更高版本，并确认安装程序已将 Python 加入 PATH。完成后重新打开启动器。

### 提示找不到 npm 或 Node.js

安装 Node.js LTS，关闭已经打开的终端或启动器窗口，然后重新运行。

### 提示 8000 或 5173 端口已被占用

关闭正在使用对应端口的其他程序，再重新启动。源码版启动器当前固定使用后端端口 `8000` 和页面端口 `5173`；Windows 便携版在 `8000` 已被占用时会自动寻找其他可用端口。

### 剧情生成很慢，可以重复点击吗

不建议。复杂剧情或格式修复可能需要更长时间，请等待当前回合结束。连续点击可能制造重复请求，却不会让猫头鹰飞得更快。

### 出现“正在整理故事弧”时还能继续玩吗

如果模型服务支持同时请求，可以继续选择行动；不支持时，剧情操作会暂时排队，并在整理完成后自动恢复。提示出现期间请不要退出或关闭游戏。

若整理途中失败，原始纪事与存档都不会受损。未完成的那批记忆会继续参与后续剧情，并在你写下下一幕之后自动重试，无需反复点击或手动找回。

### 关掉【模型思考】后，开关自己弹回去了

这通常说明当前模型服务不接受任何一种关闭思考的方式。游戏为了避免之后每一幕都生成失败，会主动恢复开启，并在开关下方写明原因；更换模型或服务后，可以再次关闭并重新探测。

如果提示“只接受部分设置”，则不是故障：游戏已经找到可用方式并保存下来，之后会自动沿用。

### 现代世代为什么没有课程与考试

这是现代线当前的玩法边界。它从四年级开始，把重心放在人物关系、战后世界与时间危机上；希望体验完整课程、选修、考试和学年成长时，可以选择邓布利多时代、亲世代或子世代，并从一年级开始这段人生。

### 可以完全避开原著主线吗

可以。时代事件仍会在背景中发生，但你可以与核心人物保持距离，经营自己的校园与人生。某些风暴可能依然波及城堡，却不要求你成为解决它的人。

### 旧存档还能继续玩吗

可以。没有现代世代字段的旧存档会继续按子世代读取。进行重要升级前，仍建议先导出或备份存档。

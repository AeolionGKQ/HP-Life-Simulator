# 霍格沃兹人生模拟器 v3.0

> **致尚未入学的年轻巫师：** 你的名字将铭刻于魔法世界之中。

猫头鹰送来的不只是一封入学通知，还有一段尚未被命运写下的人生。

《霍格沃兹人生模拟器》是一款本地运行、单人游玩的连续文字叙事游戏。你将创造自己的巫师，从收到来信、踏入对角巷或站上分院台的那一刻出发，在课程、友谊、秘密、声望与战争阴影中作出选择。

故事会记得你结识的人、许下的承诺、学会的魔法，以及那些被你悄然改变的历史。你不必成为救世主，也不必照着原著走完一条早已写好的道路——城堡的每一条岔路，都可以通往一段属于你的魔法人生。

> 本项目是免费、非商业的同人游戏，与 J.K. Rowling、Warner Bros. Entertainment 或 Wizarding World 官方无关。

## 你的七年会怎样展开

当前开放的是 **子世代（1991—1998）** 与 **现代世代（2020+）**。邓布利多时代与亲世代的入口暂时关闭，但已有存档仍可继续读取。

七个学年会真实流逝。九月意味着新的年级，三年级要选择选修课，六年级将决定 N.E.W.T. 方向，六月则会留下成绩与成长。课堂之外，你可以调查秘密、违反校规、帮助朋友、树立敌人、钻研黑魔法，甚至因为自己的选择离开霍格沃兹。

每个回合，你可以：

- 从故事给出的行动中作出选择；
- 选择“其他”，直接写下任何合理行动；
- 查看角色、纪事、羁绊、声望、课程与世界线；
- 用【干涉命运】为下一幕指定方向；
- 用【重塑命运】重新书写刚刚发生、但不符合期待的一幕。

翻阅档案不会推进时间，也不会消耗行动。你可以随时停下脚步，看看这段人生已经留下了怎样的墨迹。

## v3.0：现代世代——时间会记得你的选择

v3.0 新增现代世代线。它不是把上一代的故事换一个年代重演，而是让你在战后魔法世界的下一代中，面对家族姓氏、历史创伤、校园流言，以及一场可能再次撕裂现实的时间危机。

### 现代世代的背景

时间来到 **2020 年**。霍格沃茨大战已经过去二十多年，城堡表面恢复了日常，走廊却仍藏着封存的房间、战后遗物、被改写的纪念碑和无人愿意公开讨论的旧伤。波特、马尔福、格兰杰等家族的名字依旧会影响人们看待下一代的方式，但孩子们并不必重复父母的人生。

现代线第一版固定从 **2020 年 9 月 1 日、四年级、九又四分之三站台与霍格沃茨特快列车** 开始。你会在返校途中或抵达城堡后，逐渐认识阿不思·西弗勒斯·波特、斯科皮·马尔福、罗丝·格兰杰-韦斯莱等同期生。阿不思承受着“哈利·波特之子”的期待，斯科皮背负着马尔福家族的旧名声，而你的家庭、出身、学院和过往也会形成属于自己的压力。

### 现代线会发生什么

一架与旧历史有关的时间转换器重新成为传闻。围绕阿不思与斯科皮的友谊、阿莫斯·迪戈里的遗憾、塞德里克·迪戈里的历史锚点，以及德尔菲隐藏的真正目的，校园里的偶遇可能逐渐连成一条危险的因果链。

这条链不会强迫你按固定剧本行动。你可以：

- 帮助阿不思和斯科皮调查异常，也可以旁观、误导或阻止他们；
- 保护塞德里克、拒绝介入，或把“拯救历史”作为自己的筹码；
- 相信德尔菲、向她提供资源，或者在证据积累后揭穿她；
- 追查时间转换器与战后遗物，或完全远离核心危机，专注自己的校园、家庭、关系与未来；
- 承担每一次时间因果行动带来的现实重影、人物记忆冲突、地点回声和替代历史后果。

### 【时间扰动】玩法

现代线用【时间扰动】替代子世代的【世界线】。普通校园生活、交友、探索和练习不会自动改变时间；只有真正触及历史因果的行动，才可能让时间扰动上升。程序会根据你的实际行动、当前状态和模型提出的变化进行二次裁决，限制单回合影响范围，并在达到阈值后留下待承接的后果。

时间扰动会影响当前时间线、受到波动的命运节点、时间稳定度，以及人物对过去的记忆是否模糊、冲突或碎裂。后续剧情会根据这些状态决定哪些历史回声会找上你。

修复时间线也不会抹除你已经付出的代价。受过的伤、建立或失去的关系、获得的物品、留下的记忆和改变过的声望，都会继续成为这段人生的一部分。

### 现代线的共用系统与边界

现代线与子世代共用同一套存档和核心玩法。羁绊会根据共同经历成长，长期记忆会保留承诺、秘密和线索，故事弧会整理较远的剧情，技能、物品、词条与声望也会继续参与状态变化和叙事。

现代线保留四年级和在校身份，但为了让重点回到体验、探索和人物关系，**不启用课程、选课、考试、课程年度结算及课程技能成长系统**。这不会影响子世代的完整课程玩法。两条世代线可以同时创建、切换、导出和导入，旧存档没有现代字段时仍会按子世代解释。
### 跨端存档与版本升级

无论你想从电脑转到手机继续游玩，还是为珍贵的长篇人生留下一份备份，都可以在存档卡片上点击【导出】，将整段旅程保存为 `.hp-save.json` 文件。换到另一台设备后，在命运卷宗顶部点击【读取存档】并选择这个文件，游戏会创建一份带有“（导入）”标记的新卷宗，原有存档不会被覆盖，同一份备份也可以重复读取。

随卷宗同行的不只是角色档案，还包括剧情、纪事、人物关系、长期记忆、世界变化与已经整理好的故事弧。导入和导出本身不需要调用模型服务；如果文件无法读取，游戏会给出提示，而不是改动已有的人生。

## 写下你的巫师档案

新人生会从一份角色档案开始。你将决定：

- 姓名、性别、生日与外貌；
- 家庭出身与童年经历；
- 性格、价值观与补充设定；
- 魔杖、魔法天赋、宠物与潜在守护神；
- 初始好友、学院倾向与剧情起点。

### 让来路成为故事的土壤

纯血、混血与麻瓜出身拥有不同的童年常识和入学背景。纯血家庭的孩子或许早已习惯会动的照片与猫头鹰邮递；混血家庭连接着两个世界；麻瓜出身的孩子，则可能把那封来信当作童年怪事第一次得到答案的时刻。自定义出身会依照你写下的经历，形成独有的认知与反应。

出身会影响角色如何理解眼前的人与事，却不会替你决定学院、魔杖或未来立场。古老家族的孩子可以反对纯血至上，麻瓜出身的学生也可能主动追逐危险知识——来路塑造目光，但不会成为命运的枷锁。

### 从你想写下的那一页启程

你可以从四个时刻开始人生：收到霍格沃茨来信之前、第一次踏入对角巷、九又四分之三站台，或分院时。较晚的起点会略过此前旅程，却不会抹去童年与家庭背景；角色会带着这些往事走进第一幕。

初始好友可以多选、自定义，也可以一个都不选。故事中的地点会以可读的中文名称留在剧情与纪事中，多年后翻阅旧事时，你仍能找到那段回忆发生的地方。

不必急着写一个完美的人。一个害怕失败、渴望证明自己、对某类魔法抱有偏见，或只想平安毕业的角色，往往比全知全能的天才更值得记住。

补充设定会持续影响叙事，但不会让角色无视年龄、学籍与已经掌握的能力。潜在守护神也不会立刻回应召唤——你仍要在故事里真正学会【呼神护卫】。

初始属性生成后，如果结果与设想中的角色不符，可以展开【重新生成属性】，写下希望调整的方向，再决定是否踏入第一幕。这次校准只属于尚未开始的人生，不会改动已经启程的存档。

## 在城堡里生活

### 上课、考试与成长

你的课程会随年级变化。学习、练习和真正使用魔法会积累经验；熟练度提升后，角色在相关场景中的表现也会变得更可靠。

选修课与 N.E.W.T. 方向不是装饰：它们决定今后还能接受哪些训练，也会影响毕业前留下的成绩。退掉一门课不会抹去已经学会的本领，但它也不会继续自然成长。

### 羁绊需要共同经历

好感与信任会分别成长。一次友善招呼不会立刻换来生死之交，一场争执也未必足以摧毁多年友谊。只有真实发生过的对话、帮助、冲突、陪伴与共同冒险，才会让关系前进或后退。

关系可能从陌生走向朋友与挚友，也可能因背叛变得疏远甚至敌对。恋爱有独立的发展轨迹，并受双方年龄与真实互动约束；童年不会被过早写成爱情，条件不足时也不会凭空进入亲密阶段。

你不再只能和预设人物建立羁绊。图书馆里的陌生学生、禁林边缘的古怪巫师，或对角巷里怀揣秘密的学徒，都可能被故事真正记住，并在未来学年再次出现。

### 声望会先于你抵达房间

帮助他人、违反规则、公开使用某些魔法，都会慢慢塑造别人眼中的你。

声望较高时，陌生人可能更愿意相信你的解释；恶名增长后，畏惧、猜疑和敌意也会随之而来。若在校期间彻底滑向黑巫师之名，霍格沃兹甚至可能将你开除——课程会结束，但人生不会。你仍能以另一种身份回到这片世界。

### 原著历史是风暴，不是任务清单

魔法石、密室、逃犯、三强争霸赛与战争会在正确的年代逼近，却不会要求你逐项完成。

你可以参与、旁观、错过、误解，甚至改变某个历史节点。世界会根据日期、年级、地点、近期行动与已经改变的往事，判断哪些风声此刻应该传到你耳边。

世界线可以偏离，但每次偏离都会留下人物、声望与因果上的回声。你推开的不只是一扇门，还包括门后所有尚未写下的日子。

### 记忆让漫长人生保持连续

重要承诺、秘密、未完成线索和人物关系会被写入长期记忆。多年后重逢时，一段旧事仍可能改变对话的语气。最近发生的细节会被悉心保留，更久远的旅程则会整理成阶段性的故事弧，让漫长人生不至于在岁月中失去来路。

这些整理不会擦去任何纪事。原始剧情仍能随时翻阅；若后台整理失败，也不会损伤存档，可以前往侧边栏的【记忆管理】查看并重试。如果模型服务需要排队，羽毛笔会暂时停下，整理完成后自动恢复。

旧纪事只能阅读，不能让时间倒流；如果只是对最新一幕不满意，请使用【重塑命运】。

### 命运卷宗可以容纳不止一种人生

在存档管理界面点击【创建新存档】，就能从现有人生中抽身，重新展开一份角色档案。旧卷宗会安静地留在档案柜里，等待你下次归来。

你可以同时保留不同尝试：一位谨慎的拉文克劳、一位野心勃勃的斯莱特林，或两个出身相同却走向完全不同世界线的人。需要更换设备或留下备份时，再用【导出】与【读取存档】让其中一段人生安全远行。

## 握住命运的羽毛笔

游戏提供两种不同的叙事工具。

### 干涉命运：告诉下一幕往哪里走

当你希望某件事在接下来的剧情中发生，可以写下目标事件。故事会尝试补足通往它的合理过程，而不是毫无铺垫地把结果扔到面前。

干涉命运不会让角色绕过年龄、课程、能力与世界规则。它改变的是故事方向，不是一张无条件成功的许可证。

### 重塑命运：让这一幕重新落笔

如果当前最新剧情节奏太快、人物行为失真，或模型误解了你的意图，可以打开自由行动下方的【重塑命运】，告诉故事应当保留什么、改变什么。

```text
这一幕揭露秘密太快了。
保留“我已经察觉异常”，但让真相继续隐藏，
先通过脚步声、熄灭的烛火和人物反应制造悬念。
```

原版本造成的物品、技能、声望与羁绊变化会先被撤回，新版本只会结算一次。纪事仍停留在同一个节点，不会凭空多出一段重复历史。

简单来说：【干涉命运】推动下一幕，【重塑命运】改写这一幕。一个把羽毛笔推向岔路，一个擦去尚未干透的墨迹。

## 给第一次游玩的几条建议

- **把自由输入当成真正的行动。** 与其写“继续”，不如写清你观察谁、隐瞒什么、准备怎样的魔法。
- **给关系留下时间。** 多次共同经历比一次夸张表白更能建立可靠羁绊。
- **经常翻阅纪事和未完成线索。** 很多故事入口藏在你已经见过的细节里。
- **接受一部分失败。** 受伤、误会、失去信任和考试失利，往往会打开更独特的道路。
- **为不同念头建立不同存档。** 每份卷宗都可以拥有不同的出身、性格、学院与世界线。

## 入学前：准备你的魔法书桌

### 先领取适合设备的行李

前往 [GitHub Releases](https://github.com/AeolionGKQ/HP-Life-Simulator/releases)，打开与你准备游玩的版本一致的 Release，再从 **Assets** 中选择对应平台：

- **电脑版：** 下载 Windows 压缩包，完整解压后使用项目内的 `start_hp_simulator.bat`；
- **手机版：** 下载 Android APK，在 Android 7.0 及以上的 64 位设备上安装。

安装 APK 时，系统可能会询问是否允许浏览器或文件管理器“安装未知应用”。这是 Android 安装从 GitHub 下载的应用时的正常提示；请确认文件来自本仓库的正式 Release，并在完成后按自己的安全习惯关闭该权限。

### 你需要

- 电脑端使用 Windows 10/11；macOS 或 Linux 可采用下方的手动启动方式；
- 从源码或启动器准备电脑端环境时，需要 Python 3.12 或更高版本与 Node.js LTS；
- 安卓版需要 Android 7.0 或更高版本的 64 位设备；
- 一个支持 OpenAI-compatible Chat Completions 的模型服务；
- 对应的 Base URL、API Key 和模型名称。

无论电脑还是手机，剧情生成都需要联网访问你选择的模型服务。游戏不会附带公共 API Key。

### Windows：双击启程

1. 从对应 Release 下载电脑版并完整解压；也可以克隆仓库。
2. 双击 **`start_hp_simulator.bat`**。
3. 第一次启动时，程序会准备独立运行环境并安装所需内容，请保持网络畅通并耐心等待。
4. 浏览器打开后，在页面右上角进入模型配置，填写 Base URL、API Key 和模型名称，然后进行连接测试。

之后通常只需再次双击启动器。若浏览器没有自动出现，请手动访问：

```text
http://127.0.0.1:5173
```

### Base URL 应该怎么填

这里只填写模型服务的**根地址**，不要附加具体接口路径。

以 OpenAI 官方服务为例，应填写：

```text
https://api.openai.com
```

不要填写：

```text
https://api.openai.com/v1
https://api.openai.com/v1/chat/completions
```

## 存档、升级与隐私

电脑版的人生记录保存在项目目录下的 `data/` 中；安卓版则保存在应用自己的私有空间。

- 存档彼此独立，可以重命名或删除；
- 删除存档无法撤销；
- 电脑版升级前，建议关闭游戏并备份整个 `data/` 目录；恢复时，将备份目录放回项目根目录即可；
- 安卓版卸载应用或清除应用数据，可能会一并移除本机存档；
- 更换设备、重装应用或进行重要升级前，建议为珍贵卷宗点击【导出】，把 `.hp-save.json` 文件另存到安全位置；
- 【读取存档】会创建新的导入副本，不会覆盖当前卷宗。

导出的存档不会包含模型 API Key，但会包含角色资料、剧情、关系和记忆等完整人生记录。请像保管私人日记一样保管它，不要随意上传到公开位置。

请永远不要公开或提交：

- `config/settings.local.toml`；
- `LLM API KEY.txt` 或任何 API Key；
- `data/` 存档目录；
- `.hp-save.json` 导出文件；
- 你不希望交给他人的私密剧情内容。

游戏和存档保存在本机，但剧情生成需要把相关故事内容发送给你配置的模型服务。不同服务商的数据保留规则不同，请在开始长期存档前阅读对应的隐私政策。

## 常见问题

### 双击启动器后提示找不到 Python

安装 Python 3.12 或更高版本，并在安装时选择“添加到 PATH”。完成后重新双击启动器。

### 提示找不到 npm 或 Node.js

安装 Node.js LTS，关闭已经打开的终端窗口，再重新运行启动器。

### 模型连接测试失败

依次确认：

- Base URL 是否只填写了服务根地址；
- API Key 是否有效；
- 模型名称是否与服务商提供的名称完全一致；
- 账户是否有可用额度和该模型的访问权限；
- 模型服务是否兼容 Chat Completions；
- 当前网络是否能访问模型服务。

### 剧情生成很慢，可以重复点击吗

不建议。复杂剧情或格式修复可能需要更长时间，请等待当前回合结束。连续点击可能制造重复请求，却不会让猫头鹰飞得更快。

### 可以建立多个角色吗

可以。在命运卷宗中点击【创建新存档】，就能保留现有人生并开始另一段旅程。

### 怎样在电脑和手机之间迁移存档

在原设备的命运卷宗中找到目标存档，点击【导出】并妥善传送生成的 `.hp-save.json` 文件。然后在新设备打开命运卷宗，点击【读取存档】并选择该文件。导入后会出现一份带“（导入）”标记的新卷宗，原设备与新设备上的旧存档都不会被覆盖。

### 可以完全避开原著主线吗

可以。历史事件仍会作为时代背景发生，但你可以与核心人物保持距离，经营自己的校园生活。某些风暴可能依然波及城堡，却不要求你成为解决它的人。

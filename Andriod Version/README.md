# 霍格沃兹人生模拟器 v2.6

> **致尚未入学的年轻巫师：** 你的名字将铭刻于魔法世界之中。

猫头鹰送来的不只是一封入学通知，还有一段尚未被任何人写下的人生。

《霍格沃兹人生模拟器》是一款本地运行、单人游玩的连续文字叙事游戏。你将创造自己的巫师，从收到来信、踏入对角巷或站上分院台的那一刻出发，在课程、友谊、秘密、声望与战争阴影中作出选择。故事会记得你结识的人、说过的话、学会的魔法，以及那些被你悄然改变的历史。

你不必成为救世主，也不必照着原著走完一条早已写好的道路。你可以接近熟悉的人物，也可以远离主线，在城堡的另一条走廊里建立完全属于自己的魔法人生。

> 本项目是免费、非商业的同人游戏，与 J.K. Rowling、Warner Bros. Entertainment 或 Wizarding World 官方无关。

## 这趟旅程会是什么样

当前开放的是 **子世代（1991—1998）**。你会与哈利、罗恩和赫敏生活在同一座城堡，却不必成为他们故事里的配角。

七个学年会真实流逝。九月意味着升入新的年级，三年级要面对选修课，六年级将决定 N.E.W.T. 方向，六月则会留下成绩与成长。课堂之外，你可以调查秘密、违反校规、帮助朋友、树立敌人、钻研黑魔法，甚至因为自己的选择离开霍格沃兹。

每个回合，你可以：

- 从故事给出的行动中作出选择；
- 选择“其他”，直接写下任何合理行动；
- 查看人物、纪事、羁绊、声望、课程、信件与世界线；
- 用【干涉命运】指定下一幕必须靠近的事件；
- 用【重塑命运】重新书写刚刚发生、但不符合期待的一幕。

查看档案不会推进时间，也不会消耗行动。你可以随时停下来，翻阅自己已经走过的人生。

## v2.5：出身与命运拥有了更清晰的来路

这一版本让角色从哪里来、如何走进魔法世界，以及不满意的故事如何被重新书写，都拥有了更稳定的规则。

### 不满意这一幕，就重塑它

【重塑命运】用于改写当前最新剧情。

也许某个人突然说出了不该知道的秘密，也许节奏太快，也许模型误解了你的意图。打开自由行动下方的【重塑命运】，告诉故事你希望保留什么、改变什么，这一幕就会重新生成。

旧版本造成的物品、技能、声望和羁绊变化会先被撤回，新版本只结算一次。纪事仍停留在同一个节点，不会凭空多出一段重复历史。

例如：

```text
这一幕揭露秘密太快了。
保留“我已经察觉异常”，但让真相继续隐藏，
先通过脚步声、熄灭的烛火和人物反应制造悬念。
```

【重塑命运】修改已经写出的这一幕；【干涉命运】则为下一幕指定方向。一个像擦去羊皮纸上的墨迹，一个像把羽毛笔尖推向你想去的岔路。

### 出身不再只是一行档案

完善后的【出身】系统会持续影响角色对魔法界的认知、反应方式与叙事背景。纯血家族、混血家庭和麻瓜出身拥有各自持续有效的基础设定，并在分院前提供符合身份的默认背景；自定义出身则由故事根据你的设定推断。

出身不会替你决定剧情起点，也不会绑住魔杖、分院或玩家的行动。你可以从收到霍格沃兹来信、踏入对角巷、站上九又四分之三站台，或直接开始分院仪式的任一节点出发。

## v2.3：人与命运都开始记得更久

这一版本最重要的变化，不是多了几组数字，而是你的行动终于会在人物与世界身上留下更清晰的回声。

### 羁绊不再凭空发生

好感与信任现在会分别成长。一次友善的招呼不会立刻换来生死之交，一场争执也未必足以摧毁多年友谊。只有真正发生过的对话、帮助、冲突、陪伴和共同经历，才会让关系向前或向后移动。

关系会从陌生、相识慢慢走向朋友与挚友，也可能因背叛变得疏远甚至敌对。恋爱有独立的发展轨迹，并受双方年龄与真实互动约束；童年不会被过早写成爱情，成年阶段也不会在条件不足时凭空出现。

这意味着，一段关系不再只是剧情里的一句形容，而是一条需要共同经历来书写的支线人生。

### 陌生人也可能成为一生的重要角色

你不再只能和预设人物建立长期关系。

如果你在图书馆帮助了一名陌生学生，在禁林遇见一位脾气古怪的护林人，或在对角巷结识了一个怀揣秘密的学徒，他们都有机会被故事真正记住。原创人物会拥有自己的身份、性格、目标和恐惧，并在之后的学年里再次出现。

一场偶遇可能变成友谊、竞争、师生情谊或一段漫长的牵挂；但新人物不会因为刚登场就自动喜欢你，他们同样需要理由去信任你。

### 原著历史是风暴，不是任务清单

魔法石、密室、逃犯、三强争霸赛与战争仍会在正确的年代逼近，但它们不再要求你逐项完成。

你可以参与、旁观、错过、误解，甚至改变某个历史节点。世界会根据日期、年级、地点、近期行动和已经改变的往事，判断哪些风声此刻应该传到你耳边。

如果你推开了历史原本紧闭的门，之后的人物态度、声望与因果也会随之改变。世界线可以偏离，但每次偏离都要由你继续生活下去。

## 写下你的巫师档案

新人生会从一份角色档案开始。你将决定：

- 姓名、性别、生日与外貌；
- 家庭出身与童年经历；
- 性格、价值观与补充设定；
- 魔杖、魔法天赋、宠物与潜在守护神；
- 初始好友、学院倾向、剧情起点，以及你对魔法界的既有认知。

你可以从四个预设剧情点开始：收到霍格沃茨来信之前、第一次踏入对角巷、九又四分之三站台或分院时。其中“收到霍格沃茨来信之前”会从 1991 年 7 月 1 日家中收到猫头鹰来信开始，“九又四分之三站台”会从 1991 年 9 月 1 日的站台启程场景开始；其他选项则从各自对应的剧情节点展开。无论选择哪一种出身，故事都会严格从你选择的预设剧情点开始；自定义出身只能影响角色是否知道魔法界，以及对当前剧情的理解、情绪和反应，不能增加或跳转到其他起点。补充设定会持续影响叙事，但不会让角色无视年龄、学籍与已经掌握的能力。

纯血、混血和麻瓜出身各自拥有持续存在的基础背景介绍，并会在完成分院前提供不同的默认入学背景：纯血通常熟悉魔法界并由家人带往对角巷，混血对魔法界有基础认知并可能由家人或麦格教授陪同，麻瓜出身则通常把来信视为惊喜并由麦格教授带往对角巷。自定义出身不会套用这些预设介绍，而是由模型结合角色设定推断认知；这些只是默认剧情倾向，玩家明确选择和自由输入始终优先。

不必急着写一个完美的人。一个害怕失败、渴望证明自己、对某类魔法抱有偏见，或只想平安毕业的角色，往往会拥有更值得记住的故事。

## 在城堡里生活

### 上课、考试与成长

你的课程会随年级变化。学习、练习和真实使用魔法会积累经验，熟练度提升后，角色在相关场景中的表现也会变得更可靠。

选修课和 N.E.W.T. 方向不是装饰：它们决定今后还能接受哪些训练，也会影响毕业前留下的成绩。退掉的课程不会抹去已经学会的本领，但也不会继续获得自然成长。

### 声望会先于你抵达房间

帮助他人、违反规则、公开使用某些魔法，都会慢慢塑造别人眼中的你。

声望较高时，陌生人可能更愿意相信你的解释；恶名增长后，畏惧、猜疑和敌意也会随之而来。若在校期间彻底滑向黑巫师之名，霍格沃兹甚至可能将你开除——课程会结束，但人生不会。你仍能以别的身份回到这片世界。

### 记忆让漫长人生保持连续

重要承诺、秘密、未完成线索和人物关系会被写入长期记忆。多年以后重逢时，一段旧事仍可能改变对话的语气。

纪事页面保存已经发生的剧情节点，旧节点只能阅读，不能从过去倒退时间。若只是对最新一幕不满意，请使用【重塑命运】。

### 选择有风险，也有代价

行动可能被标记为低、中、高或致命风险。风险不是成功率按钮，而是提醒你：角色当前的能力、地点、盟友与准备，都会参与结果判断。

你可以尝试鲁莽的行动，但世界不会因为你是玩家就停止遵守自己的规则。

## 给第一次游玩的几条建议

- **把自由输入当成真正的行动。** 与其写“继续”，不如写清你观察谁、隐瞒什么、准备怎样的魔法。
- **给关系留下时间。** 多次共同经历比一次夸张表白更能建立可靠羁绊。
- **经常翻阅纪事和未完成线索。** 很多故事入口藏在你已经见过的细节里。
- **接受一部分失败。** 受伤、误会、失去信任和考试失利，往往会打开更独特的道路。
- **为不同念头建立不同存档。** 每个存档彼此独立，可以拥有完全不同的性格与世界线。

## 存档、升级与隐私

所有人生记录保存在项目目录下的 `data/` 中。

- 每个存档彼此独立，可以重命名或删除；
- 删除存档无法撤销；
- 升级游戏前，建议关闭游戏并备份整个 `data/` 目录；
- 恢复时，将备份目录放回项目根目录即可。

请永远不要公开或提交：

- `config/settings.local.toml`；
- `LLM API KEY.txt` 或任何 API Key；
- `data/` 存档目录；
- 你不希望交给他人的私密剧情内容。

剧情生成需要把相关故事内容发送给你配置的模型服务。不同服务商的数据保留规则不同，请在开始长期存档前阅读对应的隐私政策。

## 入学前：准备你的魔法书桌

### 你需要

- Windows 10 或 Windows 11（可以使用双击启动器）；
- macOS 或 Linux（需要使用下文的手动启动方式）；
- Python 3.12 或更高版本；
- Node.js LTS；
- 一个支持 OpenAI-compatible Chat Completions 的模型服务；
- 对应的 Base URL、API Key 和模型名称。

游戏与存档都保存在本机，但生成剧情时，当前故事上下文会发送给你选择的模型服务。

### 第一次启动

1. 克隆仓库，或从 GitHub 下载并完整解压游戏。
2. 双击 **`start_hp_simulator.bat`**。
3. 启动器会自动创建项目专用的 `.venv`、安装前后端依赖，并在缺少本地配置时创建 `config/settings.local.toml`。
4. 浏览器打开后，在页面右上角进入模型配置，填写 Base URL、API Key 和模型名称；也可以直接编辑本地配置文件：

```toml
[llm]
base_url = "你的模型服务根地址"
api_key = "你的 API Key"
model = "你的模型名称"
timeout_seconds = 300
temperature = 0.8
```

如果浏览器没有自动出现，请手动访问：

```text
http://127.0.0.1:5173
```

启动器只适用于 Windows。它会检查 Python 与 Node.js 版本、使用项目自己的 Python 虚拟环境、按照依赖锁文件准备前端，并在端口被其他程序占用时给出明确提示。首次安装需要联网，之后通常可以直接双击启动。

### 不使用 BAT 的备用启动方式

如果你使用 macOS、Linux，或者 Windows 启动器被安全软件拦截，可以手动启动。以下命令都要在项目根目录执行，并保持后端和前端两个终端窗口同时运行。

先准备本地配置。Windows PowerShell：

```powershell
Copy-Item config/settings.example.toml config/settings.local.toml
```

macOS 或 Linux：

```bash
cp config/settings.example.toml config/settings.local.toml
```

如果文件已经存在，不要覆盖，以免丢失已经填写的 API Key。

然后在第一个终端启动后端。

Windows PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

如果电脑没有 `py` 命令，但 `python` 指向 Python 3.12 或更高版本，可以把第一行改为：

```powershell
python -m venv .venv
```

macOS 或 Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

再打开第二个终端，启动前端。Windows、macOS 和 Linux 使用相同命令：

```bash
cd frontend
npm ci
npm run dev -- --strictPort
```

看到前后端都启动成功后，在浏览器访问：

```text
http://127.0.0.1:5173
```

第二次及之后启动时，只需分别运行后端的 `uvicorn` 命令和前端的 `npm run dev -- --strictPort`；只有依赖文件更新、虚拟环境损坏或重新下载项目时才需要再次安装依赖。

### Base URL 应该怎么填

这里只填写模型服务的**根地址**，不要附加具体接口路径。

以 OpenAI 官方服务为例，应填写：

```text
https://api.openai.com
```

不要填写：

```text
https://api.openai.com/v1
https://api.openai.com/v1/chat/completions
```

进入游戏后，也可以在页面右上角打开模型配置，修改地址、API Key 与模型名称，并先进行连接测试。

## 常见问题

### 双击启动器后提示找不到 Python

安装 Python 3.12 或更高版本，并在安装时选择“添加到 PATH”。完成后重新双击启动器。

### 提示找不到 npm 或 Node.js

安装 Node.js LTS，关闭已经打开的终端窗口，再重新运行启动器。

### 模型连接测试失败

依次确认：

- Base URL 是否只填写了服务根地址；
- API Key 是否有效；
- 模型名称是否与服务商提供的名称完全一致；
- 账户是否有可用额度和该模型的访问权限；
- 模型服务是否兼容 Chat Completions；
- 当前网络是否能访问模型服务。

### 剧情生成很慢，可以重复点击吗

不建议。复杂剧情或格式修复可能需要更长时间，请等待当前回合结束。连续点击可能制造重复请求，却不会让猫头鹰飞得更快。

### 可以建立多个角色吗

可以。创建多个独立存档，就能分别体验不同学院、性格、课程、羁绊和世界线。

### 可以完全避开原著主线吗

可以。历史事件仍会作为时代背景发生，但你可以与核心人物保持距离，经营自己的校园生活。某些风暴可能依然波及城堡，却不要求你成为解决它的人。
